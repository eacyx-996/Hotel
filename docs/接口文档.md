# 酒店管理平台 — 接口文档

- 后端基础地址：`http://localhost:8080/api`（本地开发经 Vite 代理 `/api` 转发）
- 认证方式：JWT。登录后在请求头携带 `Authorization: Bearer <token>`
- 白名单接口（无需 Token）：`/auth/login`、`/auth/register`、`/actuator`、`/error`

## 统一响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 200  | 成功 |
| 401  | 未登录或登录已过期（Token 缺失/失效） |
| 500  | 业务/系统错误，message 为具体原因 |

分页数据 `data` 结构：`{ "total": 100, "pageNum": 1, "pageSize": 10, "records": [...] }`

## 1. 认证模块 `/auth`

### 1.1 登录

- **POST** `/auth/login`（白名单）

请求体：

```json
{ "username": "admin", "password": "123456" }
```

响应 `data`：

```json
{
  "token": "eyJhbGciOiJIUzUxMiJ9...",
  "user": {
    "id": 1, "username": "admin", "realName": "系统管理员",
    "role": "ADMIN", "phone": "13800138000", "email": null
  }
}
```

说明：登录成功后将用户信息缓存至 Redis（`user:info:{id}`，24 小时）。Token 有效期 24 小时。

### 1.2 获取当前登录用户信息

- **GET** `/auth/info`
- 从 Token 解析用户 ID，返回用户实体。

## 2. 用户管理 `/user`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/user/page` | 用户分页查询 |
| GET | `/user/{id}` | 用户详情 |
| POST | `/user` | 新增用户 |
| PUT | `/user` | 修改用户 |
| DELETE | `/user/{id}` | 删除用户（逻辑删除，同时清除 Redis 缓存） |
| PUT | `/user/reset-password` | 重置密码 |

### 2.1 分页查询 `GET /user/page`

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| pageNum | long | 否 | 1 | 页码 |
| pageSize | long | 否 | 10 | 每页条数 |
| keyword | string | 否 | - | 用户名/姓名/手机号模糊搜索 |

### 2.2 新增用户 `POST /user`

```json
{
  "username": "test01", "password": "123456", "realName": "测试",
  "phone": "13900000000", "email": "t@t.com", "role": "STAFF", "status": 1
}
```

说明：密码使用 BCrypt 加密存储；`role` 取值 `ADMIN`/`STAFF`。

### 2.3 重置密码 `PUT /user/reset-password`

```json
{ "id": 2, "password": "newpass123" }
```

## 3. 房型管理 `/room-type`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/room-type/list` | 全部启用房型列表（用于下拉框，Redis 缓存 30 分钟） |
| GET | `/room-type/page` | 分页查询（参数同用户分页） |
| GET | `/room-type/{id}` | 房型详情 |
| POST | `/room-type` | 新增房型 |
| PUT | `/room-type` | 修改房型（清除列表缓存） |
| DELETE | `/room-type/{id}` | 删除房型（逻辑删除，清除缓存） |

房型字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 房型名称 |
| description | string | 描述 |
| price | decimal | 单价（元/天） |
| area | decimal | 面积（㎡） |
| capacity | int | 可容纳人数 |
| facilities | string | 设施（逗号分隔） |
| image | string | 图片地址 |
| status | int | 1 启用 / 0 禁用 |

## 4. 客房管理 `/room`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/room/page` | 客房分页查询 |
| GET | `/room/{id}` | 客房详情 |
| GET | `/room/with-type` | 客房列表（含房型名称） |
| GET | `/room/available` | 空闲客房列表（Redis 缓存 10 分钟） |
| GET | `/room/stats` | 房态统计（总数/空闲/占用，缓存 5 分钟） |
| POST | `/room` | 新增客房 |
| PUT | `/room` | 修改客房 |
| PUT | `/room/{id}/status?status={s}` | 修改房间状态 |
| DELETE | `/room/{id}` | 删除客房 |

分页查询参数：`pageNum`、`pageSize`、`keyword`（房号模糊）、`roomTypeId`、`status`。

房间状态 `status`：`0` 空闲、`1` 已预订、`2` 已入住、`3` 清洁中、`4` 维修中。

客房字段：`roomNumber`（唯一）、`roomTypeId`、`floor`、`status`、`remark`。

## 5. 订单管理 `/order`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/order/page` | 订单分页查询（keyword 搜订单号/客人姓名/手机号；orderStatus 过滤） |
| GET | `/order/{id}` | 订单详情 |
| GET | `/order/with-detail` | 订单列表（含房号、房型名称） |
| POST | `/order` | 创建订单 |
| PUT | `/order/{id}/status?status={s}` | 订单状态流转 |
| PUT | `/order/{id}/pay?payStatus={s}` | 修改支付状态 |
| DELETE | `/order/{id}` | 删除订单（逻辑删除） |

### 5.1 创建订单 `POST /order`

```json
{
  "roomId": 1, "guestName": "张三", "guestPhone": "13912345678",
  "guestIdCard": "110101199001011234",
  "checkInDate": "2026-11-01", "checkOutDate": "2026-11-03",
  "remark": "含早"
}
```

说明：

- 服务端校验房间可用性，自动计算入住天数、单价（取房型价格）与订单总额，生成订单号（`H + 日期 + 序号`）。
- 创建后房间状态置为已预订，并写入 Redis 房间状态缓存（24 小时），清除空闲房/房态统计缓存。
- 响应 `data` 包含订单 ID 与订单号。

订单状态 `orderStatus`：`0` 待确认 → `1` 已确认 → `2` 已入住 → `3` 已退房；`4` 已取消。
支付状态 `payStatus`：`0` 未支付、`1` 已支付、`2` 已退款。

状态流转时联动更新房间状态并清除相关缓存（如退房后房间置为清洁中）。

## 6. 数据统计 `/dashboard`

### GET `/dashboard/stats`

返回仪表盘全部统计数据（Redis 缓存 3 分钟）：

```json
{
  "roomStats": { "total": 16, "available": 16, "occupied": 0 },
  "orderTotal": 4,
  "totalRevenue": 1952.00,
  "todayOrders": 2,
  "dailyStats": [ { "date": "2026-10-26", "order_count": 2, "revenue": 1952.00 } ],
  "orderStatusCount": [ { "order_status": 2, "count": 2 } ]
}
```

| 字段 | 说明 |
|------|------|
| roomStats | 客房总数 / 空闲数 / 占用数 |
| orderTotal | 订单总数 |
| totalRevenue | 总营收（已支付订单金额合计） |
| todayOrders | 今日订单数 |
| dailyStats | 近 7 天每日订单数与营收（趋势图） |
| orderStatusCount | 各状态订单数量（饼图） |

## 错误处理

所有异常由全局异常处理器 `GlobalExceptionHandler` 统一捕获：

- 业务异常 `BusinessException`：返回对应业务码与提示
- 其他异常：`{ "code": 500, "message": "系统内部错误: ..." }`

未携带/携带无效 Token 访问受保护接口：HTTP 401 + `{ "code": 401, "message": "未登录或登录已过期" }`。
