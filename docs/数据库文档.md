# 酒店管理平台 — 数据库文档

- 数据库：`hotel`（MySQL 8.0）
- 字符集：`utf8mb4` / `utf8mb4_general_ci`
- 存储引擎：InnoDB
- 初始化脚本：[Backend/sql/init.sql](../Backend/sql/init.sql)
- 表数量：4 张（user、room_type、room、orders）
- 所有表均带逻辑删除字段 `deleted` 与审计字段 `create_time` / `update_time`（MyBatis-Plus 自动填充）

## ER 关系

```
user (用户)                —— 独立表，无外键关联
room_type (房型) 1 ──── n room (客房)
room (客房)      1 ──── n orders (订单)
orders.room_type_id 冗余 room_type.id（下单时快照，不随房型变更）
```

## Redis 缓存设计（非 MySQL）

| Key | 内容 | 过期时间 |
|-----|------|----------|
| `user:info:{id}` | 登录用户信息 | 24 小时 |
| `room:type:list` | 全部启用房型列表 | 30 分钟 |
| `room:available` | 空闲客房列表 | 10 分钟 |
| `room:stats` | 房态统计 | 5 分钟 |
| `room:status:{roomId}` | 订单关联的房间状态快照 | 24 小时 |
| `dashboard:stats` | 仪表盘统计数据 | 3 分钟 |

增删改操作会主动删除对应缓存键，保证数据一致性。Redis 序列化使用 GenericJackson2JsonRedisSerializer + JavaTimeModule（支持 LocalDateTime，保留类型信息）。
